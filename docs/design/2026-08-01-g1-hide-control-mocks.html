The way in is on the glass. The way out is in the gear.

Grouping your PRs by org gave every org its own gone quiet tail, and every tail its own way to open. Nothing gives them a way to close. Three fixes, one recommendation — the mocks are live, so click them.

What's actually broken

Not the reveal — that works, per org, exactly as designed. What's missing is its opposite.

When the lane wears org titles, each group's quiet rows collapse to the ratified caption: 2 gone quiet (show). Click any one of them and every group's quiet opens at once, because there is a single lane-wide preference behind them all. That part is deliberate.

But the lane-level Gone quiet header — the one that normally carries (hide) on its right edge — only renders in the flat shape. Group the lane and it never appears. So once quiet is open, nothing on screen closes it. You have to know the gear exists.

A — the tail carries its own way back recommended

Give the revealed tail label the same right-edge control the flat header has.

I left this out on purpose when I built it, reasoning that one control per group is N handles on one switch. That reasoning doesn't survive contact with the collapsed state, which already ships N handles on that same switch — one (show) per group. Refusing the symmetric (hide) isn't restraint; it's the inconsistency.

B — one control, on the lane header

Put (hide) beside the lens eye, where the lane's other lane-wide control already lives.

This matches the preference's true scope exactly: one switch, one control. The cost is distance — the thing you want to close is four rows down, and the control that closes it sits above content that has nothing to do with quiet.

C — a closing line at the lane's foot

Bring back the lane-level Gone quiet header — as a footer, after the groups.

The flat shape's header exists and is ratified; this keeps it and moves it below the content it governs, so grouped and flat differ in position rather than in vocabulary. It reads as a summary line, which is either honest or redundant depending on your eye.

The call

A. The argument that decided it isn't about ink — it's that the objection I built on was already false when I built it.

The collapsed state ships one (show) per group. If N handles on one switch were wrong, the caption would be wrong too — and the caption is ratified.

B is the better answer to how many controls should a preference have, and the worse answer to where should a control live. C is tidy in isolation and odd on a one-org lane. A is the only one where the shape you're in doesn't change the grammar you use.

Doing nothing is still legitimate

The gear does close it, and someone who opened quiet knows the preference exists. If you take that view, the change isn't code — it's turning G1 from a gap into an exemption in docs/TOPOLOGY.md, with that reasoning written next to it. What's not defensible is leaving it unrecorded, which is where this was yesterday.

Mocks are hand-built replicas at the island's real proportions and ink levels — they demonstrate structure, not pixels. The island stays dark in both page themes because the real one does.
