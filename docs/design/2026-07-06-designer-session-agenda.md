# Designer-session agenda

Each record below is one decision. Variants marked **amend** are doctrine-clean *after* the
noted amendment (all amendments are pre-applied in the mocks); **keep** means clean as written;
**kill** means struck — shown for the record, not on the table. ★ = runner's recommendation
(a default, not a decision). Ratified outcomes become decision records here / in
`loop/creative-consults.md`, then build as WP-3d/3d′/3x/4d/5g/6k.

## Build-time spec amendments (recorded, not silent)

- **`resignKey()` is not a hand-back mechanism** (WP-4d fix round, 2026-07-07): Gates.json's
  ratified variant text prescribed `keySessionActive=false + resignKey()`; AppKit documents
  `resignKey()` as a notification callback, not a key-transfer request — it hands key to
  nobody. Superseded by AppKit's designed palette machinery: `becomesKeyOnlyIfNeeded` +
  `needsPanelToBecomeKey == isEnabled` for acquisition, an order-out pulse for Esc hand-back.
  Live-witnessed (loop/evidence/wp4d-key-routing.manifest.json).
- **Gates note 2's build directive superseded** ("reset keySessionActive inside
  setExpanded(false)"): the fix round replaced the per-click latch with an eligibility gate

  verified leak-free by the focused re-verifier.
- **D-card completion morph runs the WP-3d container-morph grammar** (220/180ms,
  cubic-bezier(0.2,0,0,1)) instead of the spec's 320ms/cubic-bezier(0.32,0.72,0,1) —
